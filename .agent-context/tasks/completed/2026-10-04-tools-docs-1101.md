# Tools 1.10.1: сверка документации

## Intake / scope
- Задача: актуализировать tools docs для выпущенного 1.10.1; видео подтверждено оператором.
- Владельцы: l4setup — installation/verification, leo4proxy — routing/TLS,
  l4superv — SCM/watchdog, tools/release — inventory/signing/publication.
- Контракт: producer policy/DNS → proxy → setup probes/runtime info → engineer docs.
- Инварианты: strict TLS/admission не ослабляются, signed payload не меняется;
  operator evidence не приравнивается к измеренной agent E2E matrix.
- Проверка: сверка source/manifest, Markdown links/JSON, secret scan, diff check.
  Doc-only: без сборок, тестов Python/frontend/native, подключений к production и MQTT.

## Выполнено
- Engineer guide и quick start: версии/URL/SHA256/Authenticode, состав компонентов,
  сетевые flags, upstream verdicts и актуальные summary/status codes.
- Proxy operator guide: исправлены старые 4443/8080, сертификатный standby,
  Auto/SRV/LKG/policy/IP, bootstrap, strict TLS и runtime endpoints.
- Supervisor/Mosquitto/FFmpeg/architecture: l4setup — текущий deployment route,
  legacy ZIP/l4install явно отделён; staging и inventory points уточнены.
- Старый duplicate terminal-tools-user-guide перенаправляет к authoritative guide.
- Исторические plans/decisions сохраняют исходные версии/evidence, с current links.
- Upgrade773 ready/0 + enabled TLS valid и работающий видеопоток от оператора
  отражены в implementation handoff, component card, video contract и индексах.

## Расхождения реализации, оставленные для отдельного code change
- CLI разбирает `--smoke-only`, но [engine](../../../tools/l4setup/src/engine.c)
  не читает флаг; режим выбирается по версии/целостности. Нельзя обещать
  диагностический запуск без installer changes. Ранее предложенная команда уточнена.
- [network probe](../../../tools/l4setup/src/smoke.c) — только DNS iot.leo4.ru:
  может дать degraded при работающем numeric fallback.
- Help/comment proxy про default insecure устарели: outgoing implementation strict.
