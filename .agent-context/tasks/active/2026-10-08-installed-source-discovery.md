It checks the actual deployment.lock handle path, safe ownership/private ACL, source UUID distinct from owner UUID, protected ancestors, hardlink/reparse refusal, fixed 8MiB file budget and complete hash-chain/header/sequence/end markers. File and ancestors are held excluding writes/deletes. Any torn tail refuses; there is no create/truncate/repair. Records are exposed only after complete validation. Internal borrowed codec view is only for existing read-only typed bootstrap decoding; public API exposes no mutable L4Journal.

A SEPARATE live reader serves SYSTEM-only ACK/status snapshots while the original writer retains its deployment lock. It requires exact KnownFolders layout, private storage and canonical UUID; it opens read-only with read/write sharing, without delete sharing. Size changes and partial tails return ERROR_IO_PENDING before exposing records, for bounded retry by the remote host. Fully corrupt records fail closed. It never yields a codec view or acts as installed-source authority. Historical reader retains its exclusive-owner-lock/immutable rules.

Installed source discovery accepts only an opaque current owner journal; no caller version/old UUID/root/key input. Primary SYSTEM and exact KnownFolders roots are mandatory.
