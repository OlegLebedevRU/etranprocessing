# Minimal Static FFmpeg (Win32 x86 and Win64 x64)

Данная директория содержит минимальные статические бинарные сборки `ffmpeg.exe` для платформ x86 (Win32) и x64 (Win64), предназначенные для терминального сервиса стриминга и удаленного рабочего стола `l4desk`.

## 1. Состав артефактов

- `x86/ffmpeg.exe` — 32-битный статический исполняемый файл (размер ~26 МБ).
- `x64/ffmpeg.exe` — 64-битный статический исполняемый файл (размер ~33 МБ).
- `ffmpeg.sha256` — манифест контрольных сумм SHA-256.
- `build_ffmpeg_x86.sh` — автономный сборочный сценарий для x86.
- `build_ffmpeg_x64.sh` — автономный сборочный сценарий для x64.

## 3. Архитектура и встроенные компоненты

Оба бинарника полностью автономны (Zero-Dependency), собраны со статической компоновкой (`-static-libgcc -static-libstdc++`) и не требуют внешних DLL (всё слинковано внутрь исполняемого файла). Зависят только от базовых системных Win32 API и UCRT:

- **Кодировщик видео**: встроенный статический `libx264` (H.264 / AVC);
- **Захват экрана**: нативный Win32 `gdigrab` (GDI desktop grabber с поддержкой `-draw_mouse 1`);
- **Захват камер**: нативный DirectShow `dshow` (DirectShow capture);
- **Транспорт и протоколы**: `rtp`, `udp` (отправка видеопотока в RTP-туннель `leo4proxy` на `127.0.0.1:5004`);
- **Обработка кадров**: `swscale` (масштабирование, конвертация форматов `yuv420p`, `bgr0`, `nv12`), фильтры `scale`, `format`, `fps`.

## 4. Среда сборки и воспроизводимость

Сборка выполнена на сервере проекта в официальных кросс-компиляционных контейнерах BtbN:
- x86: `ghcr.io/btbn/ffmpeg-builds/base-win32:latest` (тулчейн `i686-w64-mingw32`, GCC 16.2.0, crosstool-NG);
- x64: `ghcr.io/btbn/ffmpeg-builds/base-win64:latest` (тулчейн `x86_64-w64-mingw32`, GCC 16.2.0, crosstool-NG);
- Исходный код: FFmpeg ветка `release/9.0`, x264 официальный репозиторий `videolan/x264`.

## 5. Совместимость с целевыми ОС

- **Windows 10 / 11 (x86 и x64)**: полная нативная поддержка "из коробки" (UCRT предустановлен).
- **Windows 7 / POSReady 7**: требует наличия Universal C Runtime (**KB2999226** или Visual C++ 2015-2022 Redistributable).
