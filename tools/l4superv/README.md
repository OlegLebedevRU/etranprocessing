# l4superv & l4install — Супервизор, Watchdog и Инсталлятор комплекса служб Leo4

Легковесный, автономный комплекс инструментов на **чистом Win32 / C** (Zero-Dependency, `/MT`) для автоматического развёртывания по принципу **«запустил и забыл»** (Zero-Touch Deployment) и непрерывной рантайм-оркестрации служб **Leo4Proxy**, **Mosquitto** и **L4Con**.

---

## 1. Решаемые задачи

1. **Развёртывание «Запустил и забыл»**: Тонкий установщик `l4install.exe` запрашивает UAC ровно 1 раз при запуске, распаковывает архив `tools.zip` в целевой каталог (`C:\l4tools`), генерирует стартовые конфигурации и регистрирует системные службы Windows (`Leo4Proxy`, `Mosquitto`, `L4Con`, `L4Superv`) в Windows Service Control Manager (SCM).
2. **Идемпотентность и самовосстановление**: Повторные запуски проверяют состояние комплекса, восстанавливают недостающие службы и обновляют конфигурации без сбоев.
3. **Рантайм-оркестрация и адаптация конфигурации**:
   - `leo4proxy` является единственным источником истины по наличию сертификата и серийному номеру устройства (`SN`).
   - `l4superv` опрашивает локальный эндпоинт `GET http://127.0.0.1:18443/_leo4/info`.
   - При отсутствии сертификата (режим **Standby**) держит Mosquitto на локальном изолированном конфиге без внешнего моста (исключая ошибки и спам в логах).
   - При появлении сертификата (выпуск через `l4pin`) динамически формирует боевой `mosquitto.conf` под актуальный `SN`, настраивает топики, ACL и перезапускает Mosquitto и L4Con.
   - При продлении сертификата (тот же `SN`) выполняет безопасный перезапуск моста.
   - При изменении `SN` перестраивает `mosquitto.conf` и перезапускает `Mosquitto` и `L4Con`.
4. **Защита от клонирования диска (Hardware Binding & Anti-Clone Auto-Reset)**:
   - Супервизор снимает стабильный аппаратный отпечаток хоста (`MachineGuid` + `VolumeSerialNumber`).
   - Если образ диска клонирован на другое физическое железо, супервизор детектирует несовпадение `hw_fingerprint`, автоматически очищает чужой сертификат из `LocalMachine\MY` и переводит комплекс в безопасный режим ожидания ввода нового PIN через `l4pin`.
5. **Встроенный сторожевой таймер (Watchdog)**:
   - Непрерывный мониторинг запущенных служб и автоматический перезапуск при сбоях.

## 2. Структура каталогов (`%L4_TOOLS_BASE_PATH%`, по умолчанию `C:\l4tools`)

```text
C:\l4tools\
├── l4superv.json                 # Главный конфигурационный файл комплекса
├── state.json                    # Файл состояния рантайма (sn, thumbprint, hw_fp, status)
├── mosquitto.conf.tmpl           # (Опционально) Пользовательский шаблон Mosquitto
│
├── l4superv\
│   ├── l4superv.exe              # Служба супервизора и CLI утилита
│   ├── l4superv_install.cmd      # Скрипт установки службы
│   ├── l4superv_uninstall.cmd    # Скрипт удаления службы
│   ├── l4superv_start.cmd        # Запуск службы
│   ├── l4superv_stop.cmd         # Остановка службы
│   ├── l4superv_restart.cmd      # Перезапуск службы
│   └── l4superv_status.cmd       # Просмотр статуса
│
├── leo4proxy\
│   ├── leo4proxy.exe             # Служба mTLS прокси и HTTP discovery
│   └── bin\ (x86, x64)
│
├── mosquitto\
│   ├── mosquitto.exe             # Служба MQTT брокера
│   ├── mosquitto.conf            # Активный сгенерированный конфиг
│   └── log\mosquitto.log         # Лог брокера
│
├── l4con\
│   ├── l4con.exe                 # Служба удалённой веб-консоли (extra_service)
│   └── bin\ (x86, x64)
│
└── l4pin\
    ├── l4pin.exe                 # CLI-утилита установки сертификата по PIN
    └── bin\ (x86, x64)
```

## 3. Формат поставки и процесс первого запуска

Пользователю передаётся **2 файла**:
1. **`l4install.exe`** — исполняемый файл установщика со встроенным манифестом повышения прав `requireAdministrator`.
2. **`tools.zip`** — архив, содержащий каталоги утилит (`leo4proxy`, `mosquitto`, `l4con`, `l4pin`, `l4superv`).

### Сценарий установки:
1. Пользователь запускает `l4install.exe` (или `l4install_run.cmd`).
2. Windows отображает стандартный запрос UAC (один раз).
3. `l4install.exe` находит `tools.zip`, распаковывает дерево утилит во встроенном высокопроизводительном декомпрессоре (`miniz.c`), генерирует `l4superv.json`, `state.json`, Standby `mosquitto.conf` и регистрирует службы.
4. Служба `L4Superv` стартует автоматически под учётной записью `NT AUTHORITY\SYSTEM` и берёт под контроль весь жизненный цикл.

## 4. Сборка (Build Instructions)

Для компиляции используется **MSVC Build Tools 2022** или **MinGW GCC**:

```cmd
cd tools\l4superv
build.cmd
```

Результаты сборки в каталоге `bin/`:
* `bin\l4superv.exe` — универсальный бинарник службы супервизора.
* `bin\l4install.exe` — универсальный бинарник установщика.
* `bin\x86\` и `bin\x64\` — архитектурно-специфичные сборки.

### Упаковка дистрибутивного архива `tools.zip`:
```cmd
pack_zip.cmd
```
Скрипт собирает актуальные бинарники всех инструментов в `obj/staging` и упаковывает архив `bin/tools.zip`.

## 5. Требования к упаковке ZIP для полной совместимости

При самостоятельной сборке или обновлении архива `tools.zip` необходимо соблюдать структуру путей внутри архива:
* Корневой уровень архива должен содержать папки компонентов: `leo4proxy/`, `mosquitto/`, `l4con/`, `l4pin/`, `l4superv/`.
* Метод сжатия: стандартный **Deflate (метод 8)** или **Stored (метод 0)** без шифрования и без ZIP64 extensions (поддерживается стандартными утилитами `Compress-Archive`, `7-Zip`, `WinRAR`, `zip`).

## 6. Использование CLI Команд

### `l4install.exe` (Параметры установщика):
```text
Usage: l4install.exe [OPTIONS]

  --dest <dir>       Целевой каталог (по умолчанию: C:\l4tools или %L4_TOOLS_BASE_PATH%)
  --zip <path>       Путь к архиву tools.zip (по умолчанию: автопоиск рядом с exe)
  --silent, /S       Тихий режим без вывода в консоль
  --no-services      Только распаковка без регистрации служб в Windows SCM
  --help, -h         Справка
```

### `l4superv.exe` (Параметры супервизора):
```text
Usage: l4superv.exe [OPTIONS]

  --console, -f      Интерактивный запуск супервизора в текущей консоли
  --install, -i      Установка службы L4Superv в Windows SCM
  --uninstall, -u    Удаление службы L4Superv из Windows SCM
  --start            Запуск службы L4Superv
  --stop             Остановка службы L4Superv
  --restart          Перезапуск службы L4Superv
  --status           Просмотр статуса всех служб и состояния оркестратора
  --check            Единоразовая проверка и синхронизация конфигов
  --help, -h         Справка
```
