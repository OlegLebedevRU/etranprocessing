# Модуль видеозахвата `l4capture` (tools\l4capture)

## Режимы Medium и HD

Medium кодирует до 1280×960 при 15 кадрах/с с целью 1300 кбит/с и настройкой максимума 1650 кбит/с. HD кодирует до 1920×1080 при 25 кадрах/с с целью 2500 кбит/с и максимумом 3000 кбит/с. Пропорции исходного экрана сохраняются, увеличение малого растра не выполняется. Для 800×600 цели понижаются до 900/1100 кбит/с (Medium/HD). Изменение качества для малого терминала не требует создания лишних пикселей.

Целевые суммарные бюджеты WAN — около 2000 кбит/с для Medium и 3500 кбит/с для HD при одном зрителе. Параметры кодировщика не задают строгий сетевой предел: RTP, WebRTC, TLS, управляющий трафик и всплески ключевых кадров требуют отдельного измерения на сервере и в браузере.

Целевая папка для нативного исходного кода, сборочных скриптов, тестов и артефактов модуля видеозахвата `l4capture.exe`.

---

## 1. Назначение каталога

- **Исходный код на C:** реализация нативного дочернего процесса Windows (`l4capture.exe`) для захвата рабочего стола (GDI / DXGI), масштабирования растра, программного и аппаратного кодирования H.264 (OpenH264 / Media Foundation MFT) и передачи видеопотока по RTP/RTCP на локальный порт 5004/5005.
- **Сборочные скрипты:** сценарии сборки MSVC под x86 и x64 со статической линковкой CRT (`/MT`).
- **Тесты:** модульные и интеграционные тесты конвейера захвата, кодирования, IPC-протокола, таймеров deadline и безопасности.
- **Артефакты:** скомпилированные бинарные файлы `bin/x86/l4capture.exe`, `bin/x64/l4capture.exe` и `bin/l4capture.exe`.
- **Лицензии и SBOM:** лицензионные материалы OpenH264 (BSD-2-Clause) и перечень компонентов (SBOM).

## 2. Разделение с документацией и каскадом

- **Документация, промпты, контроллер каскада и handoff-журнал:** находятся строго в `docs\l4capture\` (`docs/l4capture/l4capture_arch_final.md`, `docs/l4capture/prompts/`, `docs/l4capture/handoffs/`).
- **Запрещено использовать `l4desk-service` для размещения файлов проекта `l4capture`.**

## 3. Целевая структура реализации

```text
tools\l4capture\
├── include\           # Заголовочные файлы и C-контракты (ICaptureBackend, IEncoderBackend, IPC)
├── src\               # Исходный код на C
│   ├── capture\       # GDI и DXGI захват экрана и курсора
│   ├── codec\         # OpenH264 и Media Foundation MFT энкодеры
│   ├── pipeline\      # Масштабирование, конвертация цветов (I420/NV12), pacing
│   ├── rtp\           # RTP Single NAL/FU-A пакетизатор, RTCP отправитель
│   ├── ipc\           # Двусторонний IPC по анонимным пайпам, фрейминг
│   └── main.c         # Точка входа, lifecycle и safety-контроль
├── tests\             # Модульные и интеграционные тесты
├── build.cmd          # Скрипт сборки под MSVC x86/x64
├── bin\               # Скомпилированные артефакты
│   ├── x86\
│   └── x64\
└── README.md          # Настоящее описание
```
