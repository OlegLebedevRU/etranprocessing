# Руководство пользователя Leo4 Tools (Quick-Start)

Краткое руководство по быстрому запуску и управлению комплексом терминальных утилит платформы **etranprocessing / Leo4**.

> 📖 **Полное авторитетное руководство инженера:**  
> Исчерпывающее описание целевого процесса Zero-Touch, матрицы начальных состояний Windows (S1–S10), кодов возврата, структуры отчета `install_summary.json` и процедур устранения неполадок приведено в документе:  
> **[`docs/term_tool-user-guide.md`](../docs/term_tool-user-guide.md)**.

---

## 1. Быстрый старт (Zero-to-Start)

Комплекс утилит развертывается с помощью единого установщика **`l4setup.exe`** (Single-Binary Bootstrapper), автоматически подбирающего разрядность и настраивающего окружение.

### 1.1. Получение дистрибутива
Дистрибутив загружается напрямую из публичного Generic-реестра артефактов:
```cmd
curl.exe -O https://l4tools-generic.ar.cloud.ru/l4tools/1.6.0/l4setup.exe
curl.exe -O https://l4tools-generic.ar.cloud.ru/l4tools/1.6.0/SHA256SUMS
certutil -hashfile l4setup.exe SHA256
```

### 1.2. Запуск установки
- **Интерактивно (1 клик):** запуск двойным кликом `l4setup.exe` от имени Администратора.
  - Если на терминале **уже установлен действующий сертификат** (S9), инсталлятор переиспользует его без запроса PIN.
  - Если сертификат отсутствует, введите выданный 6-значный PIN-код или нажмите «Пропустить — ввести позже».
- **Автоматически из командной строки / скриптов:**
  ```cmd
  :: Установка с переиспользованием существующего сертификата (или отложенным PIN):
  l4setup.exe --silent

  :: Установка с первичным выпуском сертификата по PIN:
  l4setup.exe --silent --pin 986821
  ```

После завершения установки в `C:\l4tools` формируются итоговые файлы:
- `C:\l4tools\install_summary.json` — машиночитаемый отчет (статус `ready`, коды smoke-проб);
- `C:\l4tools\l4setup.log` — журнал работы.

## 2. Основные команды управления службами

Все службы комплекса зарегистрированы в Windows SCM и управляются через супервизор `l4superv.exe` (`C:\l4tools\l4superv\l4superv.exe`):

| Команда | Описание |
|---|---|
| `l4superv.exe --status` | Просмотр статуса всех компонентов (`Leo4Proxy`, `mosquitto`, `L4Con`, `L4Superv`, `l4desk`), PID процессов и аппаратного профиля (`state.json`). |
| `l4superv.exe --tick` | Отправка форс-такта оркестрации (`SERVICE_CONTROL 128`) работающей службе `L4Superv`. |
| `l4superv.exe --check` | Однократный такт проверки конфигураций и синхронизации. |
| `l4setup.exe --smoke-only` | Экспресс-диагностика работающего комплекса (проверка портов, захвата экрана и ответа proxy). |
| `l4setup.exe --repair` | Принудительное восстановление поврежденных файлов и служб. |

## 3. Выпуск и проверка сертификатов (`l4pin.exe`)

Модуль `C:\l4tools\l4pin\l4pin.exe` обеспечивает привязку клиентских сертификатов mTLS к криптопровайдеру Windows CNG:

```cmd
:: Проверка состояния установленного сертификата (без изменений):
l4pin.exe --check

:: Проверка в формате JSON:
l4pin.exe --check --json

:: Ввод отложенного PIN-кода (при отсутствии сертификата):
l4pin.exe <PIN>
```

> ⚠️ **Предостережение:**  
> Никогда не используйте команду `l4pin.exe --force <PIN>` без явного указания администратора платформы, так как это приведет к удалению действующего сертификата терминала!
