# Пакет развертывания Leo4 Tools для Windows 7 SP1 (32-bit x86)

Специализированный автономный дистрибутив утилит платформы **etranprocessing / Leo4 Tools** и брокера **Mosquitto No-SSL**, скомпилированный специально для работы на **32-разрядных версиях Windows 7 SP1** (а также Windows Embedded Standard 7, POSReady 7).

---

## 1. Особенности сборки для Windows 7 SP1

1. **Таргетинг компилятора MSVC**:
   - Все бинарники собраны со строгим таргетингом `/D_WIN32_WINNT=0x0601` (Windows 7).
   - В PE-заголовках исполняемых файлов жестко зафиксирована подсистема `/SUBSYSTEM:CONSOLE,6.01` (MajorOperatingSystemVersion = 6, MinorOperatingSystemVersion = 1, MajorSubsystemVersion = 6, MinorSubsystemVersion = 1).
   - Архитектура — строго **x86 (32-bit)**.
   - Статическая компоновка рантайма C (`/MT`), исключающая потребность в установке внешних пакетов Visual C++ Redistributable.

2. **Полное отсутствие зависимости от OpenSSL**:
   - В проекте OpenSSL не используется.
   - Все криптографические операции и взаимная аутентификация по mTLS выполняются через нативный системный стек Windows Security Support Provider Interface (**SChannel**), **CryptoAPI** и **CNG (NCrypt)**.

3. **Брокер Mosquitto v2.1.2 No-SSL**:
   - Собрана версия брокера без TLS (`WITH_TLS=OFF`), так как внешнее шифрование mTLS на терминале прозрачно осуществляет локальный туннель `leo4proxy` через Win32 SChannel.
   - Включена поддержка моста MQTT v5.0 (протокол моста v50 для связки с `leo4proxy` и бэкендом).
   - **Устранена несовместимость с ядром Windows 7**: исключен прямой импорт отсутствующей в Windows 7 функции `GetSystemTimePreciseAsFileTime`. Реализован безопасный runtime-fallback на `GetSystemTimeAsFileTime`, что предотвращает ошибку загрузки DLL/точки входа при старте сервиса.
   - Встроена статическая библиотека cJSON, скомпилированная с флагами `/MT` и `/D_WIN32_WINNT=0x0601`.

Файл | Разрядность | Назначение

## 3. Состав пакета утилит (`tools.zip`)

При установке в целевой каталог `C:\l4tools` извлекаются:

Компонент | Бинарный файл | Описание
---|---|---
**`leo4proxy`** | `leo4proxy.exe` | SChannel mTLS туннель и обратный шлюз для связи с брокером и бэкендом.
**`mosquitto`** | `mosquitto.exe` | Локальный брокер сообщений MQTT v5.0 No-SSL.
**`l4con`** | `l4con.exe` | Агент удаленной диагностики и выполнения команд по защищенному MQTT.
**`l4superv`** | `l4superv.exe` | Супервизор и watchdog процессов терминального узла.
**`l4pin`** | `l4pin.exe` | Утилита выпуска, привязки и проверки сертификатов терминала по PIN.
**`l4sql`** | `l4sql.exe` | Консольная утилита выполнения SQL-запросов через системный драйвер ODBC.
**Документация** | `terminal-tools-user-guide.md` | Полное руководство оператора по управлению комплексом утилит.

## 4. Порядок установки на Windows 7 SP1

1. Скопируйте содержимое папки `tools/dist_win7_sp1` на целевую машину в любой каталог (например, на рабочий стол или `C:\dist`).
2. Запустите файл `l4install_x86.cmd` (или `l4install.cmd`) с правами Администратора:
   ```cmd
   l4install_x86.cmd
   ```
3. Инсталлятор:
   - Распакует все 32-битные компоненты в `C:\l4tools`;
   - Добавит пути утилит в системную переменную `PATH`;
   - Настроит права доступа и сгенерирует начальную конфигурацию Mosquitto;
   - Зарегистрирует и запустит системные службы Windows (`Leo4Proxy`, `Mosquitto`, `L4Con`, `L4Superv`).

---

## 5. Параметры командной строки инсталлятора

```cmd
l4install_x86.exe [ПАРАМЕТРЫ]

Параметры:
  --dest <путь>      Целевая директория установки (по умолчанию: C:\l4tools)
  --zip <путь>       Путь к архиву tools.zip (по умолчанию: поиск рядом с exe)
  --silent, /S       Тихий режим без вывода сообщений в консоль
  --no-services      Только распаковка файлов без регистрации служб Windows
  --help, -h         Вывод справки по параметрам
```
