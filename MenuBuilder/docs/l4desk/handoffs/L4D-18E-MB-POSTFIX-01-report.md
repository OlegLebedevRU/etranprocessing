## Контракт новой политики

- Источник данных — `orgs` в общей БД. MenuBuilder пишет только по действию
  суперпользователя и отдаёт политику через `/api/auth/me`.
- `site_mode`: `classic`, `l4desk`, `both`; `default_site`: Classic/L4Desk или
  `NULL` (исторический выбор по роли). При одном разрешённом сайте он становится
  и сайтом по умолчанию. В обеих версиях пользователь может переключаться.
- `classic_licenses_enabled` и `l4desk_licenses_enabled` управляют пунктами меню
  и прямыми маршрутами страниц. Финансовые API, тарифы и проводки не меняются.
- Роль 4 в режиме только L4Desk получает доступ к видео при наличии разрешения;
  при отсутствии разрешения видит штатный отказ. Список терминалов с PIN ей не
  открывается.
- `028` добавляет четыре поля и проверки значений. Все существующие tenant
  получают `both`, `NULL`, `true`, `true`, поэтому прежняя навигация сохраняется.

## Порядок внедрения

1. Сверить production с исходным состоянием: Alembic `027`, текущие image
   ProcessingBackend/MenuBuilder, frontend `dist`, nginx и действующие флаги.
   Сохранить точные image ID и копии `dist`/конфигурации для отката.
2. Установить additive Alembic `028` через стандартный ProcessingBackend image.
   Проверить `alembic current` и значения по умолчанию у существующих
   организаций. Startup MenuBuilder требует одновременно обновить проверку
   совместимости схемы до `028`; одной замены модели недостаточно.
3. Промотировать MenuBuilder backend со всеми post-18E коммитами и новой общей
   ORM; затем frontend `dist`. Не собирать образ из устаревшего host source.
4. Прочитать `/api/auth/me` и карточку организации под тестовыми ролями.
   Для проверок изменения политики использовать тестовую организацию; под
   `violanta-tmp` выполнять только чтение и переходы между страницами.
5. Проверить ширину списка L4Desk при 1366 px, обе страницы лицензий и прямые
   URL после отключения каждой страницы, редактирование тестового терминала,
   возврат прежней настройки. После smoke передать независимому контроллеру.

При ошибке UI/backend вернуть сохранённый `dist`. Образ MenuBuilder для отката
должен принимать ревизию `028` в startup guard: исходный image `fce907d`
допускает только `027` и после миграции не запустится. Откат схемы отдельно
допускается только после остановки всех новых readers/writers и проверки данных.
