# Материалы лендинга L4Desk

Исходники страницы — `../site/`, серверный обработчик формы — `../contact/`,
Docker и nginx — `../docker/` и `../docker-compose.yml`.

| Каталог | Содержимое |
|---|---|
| `screenshots/` | Оригинальные PNG актуальных и предыдущих кадров интерфейса |
| `illustrations/` | Иллюстрация работы с парком через браузер из предыдущей версии |
| `briefs/` | Редакционный план и визуальное дополнение с источниками утверждений |
| `history/` | Исторический патч кнопок регистрации и входа |

Материалы перенесены из `l4desk-service/docs/` без изменения изображений;
дубли из `l4desk-landing/images/` удалены после сверки SHA-256.
Архитектура сервиса и технические handoff-документы остаются в `l4desk-service`.
Ссылки в брифах пересчитаны относительно нового расположения.

Текущие четыре кадра в `site/images/` подготовлены в WebP: превью 480/960 px
и полная версия исходного разрешения. Текущий первый экран — «Удалённое
управление. В браузере.». Кадр L4MCP подписан как демонстрационный пример.

Для повторной подготовки WebP используйте Pillow: RGB, LANCZOS,
quality=84/method=6 для превью, quality=94/method=6 для полной версии.
Оригинальные PNG не изменять. Материалы исключены из Docker build context.
