# Changelog — ProcessingBackend

## Unreleased — FM v2 only

FM admission requires protocol v2 and MQTT navigation/user-write/drive capabilities; PB listing operations/results removed.

## 2026-10-05 — File manager

FM agent mTLS metadata API, signed versioned S3 grants/checksum verification, additive migration032 and commit receipt reconciliation; file bodies never enter PB.

Значимые изменения терминального processing-контура. Журнал описывает текущее состояние продукта, а не последовательность промежуточных реализаций.

## Unreleased

### Added

- Policy v1 поддерживает опциональные env-настройки endpoint host/port, публичные IPv4 fallback и TTL кэша. Неверные routing-данные не меняют admission; без настроек сохраняется прежний JSON.

- Терминальный `GET /api/leo4proxy/policy` возвращает вычисляемое MQTT/RTP-разрешение по `Terminal.is_active`, факты запрета и независимый HTTPS-флаг, пока всегда `true`. Отключенные терминалы продолжают получать политику через mTLS; ответы не кешируются.
- Миграция 028 расширяет организацию настройками доступных версий сайта и видимости страниц лицензий; значения по умолчанию сохраняют существующую навигацию.

### Removed

- Alpha MCP-сервис вынесен в `MenuBuilder/l4mcp`; ProcessingBackend больше не содержит пользовательский MCP runtime.

### Fixed

- Публичный mTLS ingress не пропускает внутренний API выдачи PIN; терминальные XML-маршруты сертификатов сохранены.

## 2026-08-31

### Added

- Расчёт `GateGauge` работает через детерминированный движок слотов и битовых масок; одинаковый набор входных данных даёт воспроизводимый результат.
- События gauge-контура публикуются и принимаются через RabbitMQ/MQTT, а lifecycle приложения управляет подключением к шине.
- Alembic содержит миграции общей платформенной схемы для каталога услуг, версионирования меню и унифицированной модели активности терминала.

### Changed

- Активность терминала хранится в `terminals.is_active`, а лицензия отвечает за срок действия через `licenses.expires_at`; проверка terminal access использует эти независимые признаки.
- `ProcessingBackend` остаётся единственным владельцем цепочки Alembic для общей БД, которой пользуются processing-контур и MenuBuilder.
- Модели общей предметной области подключаются из пакета `etranprocessing_db`, без дублирования ORM-сущностей в backend.

### Removed

- Из лицензий удалены устаревшие поля `is_active`, `renewal_enabled` и `deactivation_requested_at`; состояние доступности больше не распределено между терминалом и лицензией.

### Fixed

- Истёкшие лицензии терминалов с отключённым продлением при миграции корректно переводятся в неактивное состояние до удаления прежних полей.
- Проверка сертификата и лицензии больше не зависит от удалённых признаков лицензии.
