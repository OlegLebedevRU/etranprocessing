# Браузерная часть видео: изменение после принятого 18E

Этот документ — индекс для проверки `L4D-18F-DOCS-FIX-01`, а не новый
`HANDOFF`, разрешение на чтение соседних исходников или запись о приёмке.
Принятый `H-L4D-18E-MB-v1` остаётся неизменным. Текущая ветка
`feat/l4capture-medium-hd-input` не считается production-версией фронтенда
до проверки фактических `dist` и browser smoke.

## Происхождение

| Изменение MenuBuilder frontend | Опубликованный source commit | Статус |
|---|---|---|
| Видеостраница занимает доступное пространство, сворачивает боковую навигацию, компактно размещает действия; режимы названы Medium/HD, есть выбор подгонки кадра и исходного размера | `239345bc233eb94afef5d3e3458df3568cb30950` | Код опубликован; runtime-версию сверить заново |
| F8 и кнопка «Удержать курсор» локально останавливают отправку перемещения, кликов и клавиш; повторное нажатие возобновляет ввод, выход из управления сбрасывает паузу | `23cc4cb97372dde6c448d93dd3201cda78ad59e9` | Код опубликован в ветке `feat/l4capture-medium-hd-input`; production-деплой не подтверждён |

Оба изменения относятся к browser consumer MenuBuilder. F8 не создаёт новую
MQTT-команду, не меняет lease или серверный контроль доступа. Сочетания
Alt+F4/Win+D по-прежнему проверяются агентом и его адресной политикой;
браузерная пауза не является разрешением этих действий.

## Проверка для итогового реестра 18F

1. Сверить source commit фронтенда, digest собранного `dist` и фактически
   раздаваемые assets. Исторический 18E frontend manifest не доказывает
   присутствие этих изменений.
2. В браузере с активным управлением проверить Medium и HD: целый кадр,
   подгонку/исходный размер, обычное и полноэкранное окно, действия Start/Stop.
   Для источника 800×600 убедиться, что кадр не увеличен на стороне агента.
3. При F8 и нажатии кнопки проверить, что удалённый курсор остаётся на своей
   точке при перемещении локальной мыши к панели быстрых действий; клики по
   видео и клавиши не пересылаются. Затем возобновить ввод и проверить сброс
   паузы при выходе из управления. Учитывать, что отправка pointer move уже
   ограничена поверхностью видео.
4. Проверить, что быстрые действия работают по действующей авторизации и
   политике агента; при недоступном control lease пауза не создаёт обход.
5. Зафиксировать browser evidence и rollback версии фронтенда. Локальные
   `npm run build` и 66 Vitest тестов для `23cc4cb` прошли, но не заменяют
   эти production/browser проверки.

Если delta включена в целевой выпуск, отсутствие проверки deployed assets и
browser smoke записывать как `PENDING`/`DRIFT` в матрице 18F. Не приписывать
ей статус `ACCEPTED` из исторического handoff 18E и не объявлять
`CLOSED_ACCEPTED` при незакрытом обязательном пункте.
