Экспорт не читает и не пересобирает код MenuBuilder, не вызывает API и
не подтверждает состояние сервера после приёмки 17E. Для документации

проверяет remote commit и Git/raw SHA-256 обоих файлов и добавляет
append-only `ACCEPTED` handoff со статусом `DOCS_PUBLISHED`.
