# Проект `l4capture` (Нативный модуль видеозахвата)

Проект нативного легковесного Windows-модуля видеозахвата (`l4capture.exe`) для замены FFmpeg при desktop-трансляциях терминалов L4Desk.

---

## 1. Назначение и целевое размещение файлов

| Назначение | Целевая папка | Описание |
|---|---|---|
| **Документация и архитектура** | `docs\l4capture\` | Архитектурный релиз `l4capture_arch_final.md`, историческая альфа-записка `l4capture_arch_alfa.md`, регламенты. |
| **Промпты и каскад задач** | `docs\l4capture\prompts\` | Задания агентам каскада L4C (11 шагов, 4 фазы), стандарт промптов `PROMPT-STANDARD.md`, шаблоны `CORRECTIVE-PROMPT-TEMPLATE.md`. |
| **Контроллер каскада и журнал** | `docs\l4capture\prompts\` | Промпт Агента-Контроллера `HANDOFF-CONTROLLER-PROMPT.md` и единый неизменяемый append-only журнал передачи контрактов `contract-handoff.md`. |
| **Отчёты и кандидаты handoff** | `docs\l4capture\handoffs\` | Отчёты выполнения шагов `<PROMPT_ID>-report.md` и блоки кандидатов `<PROMPT_ID>-candidate.md` в формате `DETACHED_V1`. |
| **Контракты и схемы** | `docs\l4capture\contracts\` | Спецификации интерфейсов, схемы данных и проверочные фикстуры. |
| **Код, скрипты и результаты** | `tools\l4capture\` | Нативный исходный код на C (`src/`, `include/`), сборочные скрипты (`build.cmd`), тесты (`tests/`), бинарные артефакты (`bin/`), SBOM и лицензии. |

---

## 2. Ключевые правила и ограничения

1. **Строгий запрет использования `l4desk-service`:**
   - **Запрещено использовать `l4desk-service` для размещения файлов проекта `l4capture`.**
   - Сервис `l4desk-service` обслуживает отдельный независимый каскад сервиса L4Desk.
   - Проект `l4capture` полностью автономен: все промпты, документация, контроллер каскада и журнал handoff ведутся исключительно в `docs\l4capture`.

2. **Разделение документации/промптов и кода:**
   - Промпты, контроллер каскада и документация размещаются в `docs\l4capture`.
   - Исходный код на C, сборочные скрипты, тесты и скомпилированные артефакты размещаются в `tools\l4capture`.

3. **Неизменяемый журнал передачи контрактов (`contract-handoff.md`):**
   - Все межэтапные передачи между 11 агентами реализации каскада L4C фиксируются через журнал `docs/l4capture/prompts/contract-handoff.md`.
   - Добавление записей разрешено только Агенту-Контроллеру каскада методом append-only после верификации SHA-256 реальных байтов артефактов и sequence gate.
   - Для вехи M-1 (шаг L4C-06) обязателен личный вердикт владельца «НОРМ».
