# Событие 75: сертификат и инвентаризация L4 Tools

Источник: `l4con` (`extra_service`). После успешного MQTT CONNACK он публикует
событие в `dev/{SN}/evt` с QoS 1, без retain. Перед публикацией `l4con`
проверяет совпадение SN и отпечатка активного сертификата Leo4Proxy с локальным
сертификатом терминала. Присутствие сервиса по прежнему публикуется в
`dev/{SN}/svc`.

Оболочка сообщения сохраняет действующий контракт: `101` — уникальный ID
события, `102` — время публикации UTC, `200` — код `75`, `300` — массив
свойств. Время в `102` не является временем сборки или установки файла.

Свойства `300[0]`:

| Тег | Значение |
|---|---|
| `324` | SN терминала |
| `440` | `l4con` — источник события |
| `441` | Отпечаток активного сертификата |
| `442` | Серийный номер сертификата |
| `443` | Срок действия сертификата UTC |
| `444` | Массив установленных EXE |
| `445` | `installed_version` из успешного `install_summary.json`, затем из `state.json` при отсутствии успешного отчёта; либо `null` |

Каждый элемент `444` содержит `name`, относительный `path`, `arch`,
`present`, `file_version` (PE FILEVERSION или `null`), `size` в байтах,
`modified_utc` (время изменения файла UTC или `null`) и `sha256` (hex или
`null`). Путь содержит `/`, чтобы оставаться корректной строкой JSON.
Отсутствующий или недоступный для чтения EXE имеет `present=false`.
Версия пакета `445` и PE-версия каждого файла — разные величины. Некоторые
ресурсы PE содержат старую версию, поэтому для точного сравнения бинарников
используйте SHA-256.

```json
{
  "101": 123456,
  "102": "2026-09-29T12:00:00Z",
  "200": 75,
  "300": [{
    "324": "<SN>",
    "440": "l4con",
    "441": "<certificate thumbprint>",
    "442": "<certificate serial>",
    "443": "2030-01-01T00:00:00Z",
    "444": [{
      "name": "l4desk",
      "path": "l4desk/l4desk.exe",
      "arch": "default",
      "present": true,
      "file_version": "1.7.6.0",
      "size": 123456,
      "modified_utc": "2026-09-29T11:55:00Z",
      "sha256": "<64 hex characters>"
    }],
    "445": "1.9.1"
  }],
  "correlationData": "<UUID>"
}
```

`l4con` проверяет состояние каждые 60 секунд и публикует новый event 75 только
при изменении сертификата, версии пакета или набора файлов/их хешей. При
ошибке публикации повторяет попытку через 15 секунд. App1 сохраняет payload
как JSON без схемы для отдельных тегов; тег `444` остаётся вложенным JSON.
