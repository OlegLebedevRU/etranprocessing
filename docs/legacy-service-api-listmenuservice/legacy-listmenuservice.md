# Исследование сервиса ListMenuFile

## 1. Обзор

**ListMenuFile** — GET-эндпоинт в PlaterraApiFrontService (OWIN self-hosted Web API 2), возвращает иерархическое меню услуг для киоска.

**Endpoint:** `GET /ListMenuFile/Get`  
**Аутентификация:** `[Authorize]` — X.509 клиентский сертификат  
**Файл:** `PlaterraApiFrontService/Controllers/ListMenuFile.cs`

---

## 2. Полный флоу

```
Киоск (терминал)
    │
    │  GET /ListMenuFile/Get
    │  + Authorization: ClientCertificate <PEM>  (или TLS client cert)
    │  + hostName header / query param
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  APIKeyAuthenticationMiddleware                       │
│  1. Извлекает сертификат (из TLS или header)         │
│  2. Парсит terminalNumber из OU поля сертификата     │
│     (или из query param terminalNumber)              │
│  3. Вызывает SP AuthHostTerminal(hostName, termNum)  │
│     → возвращает dict<typeId, hkpId>                 │
│  4. Создаёт ClaimsIdentity с MyAuthKey JSON:         │
│     { HostName, TerminalNumber, ProvTypes }           │
└──────────────────────┬──────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────┐
│  ListMenuFileController.Get()                        │
│                                                      │
│  1. authKey = User.Identity.GetAuthKey()             │
│     → десериализует MyAuthKey из Claims              │
│                                                      │
│  2. SELECT org_id FROM Kiosks                        │
│     WHERE number = @TerminalNumber                   │
│     → получает org_id киоска                         │
│                                                      │
│  3. SELECT * FROM tb_GS_Group                        │
│     WHERE org_id = @org_id ORDER BY number           │
│     → получает все группы (категории) организации    │
│                                                      │
│  4. Для каждой группы:                               │
│     SELECT * FROM tb_GS_Service                      │
│     WHERE group_id = {g.Id} ORDER BY tsp_code        │
│     → получает услуги в каждой группе                │
│                                                      │
│  5. groups.GenerateTree(Id, ParentId)                │
│     → строит дерево из плоского списка групп         │
│     (ParentId=NULL → корень, ParentId=0 → дочерние)  │
│                                                      │
│  6. Convert(root, tree)                              │
│     → рекурсивно конвертирует TreeItem<Group>        │
│       в clsMenuItem (имена, коды, цены, услуги)      │
│                                                      │
│  7. Если корневых элементов > 1:                     │
│     → схлопывает все корневые в items[0].items       │
│                                                      │
│  8. Возвращает JSON с Formatting.Indented            │
└─────────────────────────────────────────────────────┘
```

## 3. Таблицы и модели данных

### 3.1. Таблица `Kiosks` (база: Service)

Связывает номер терминала с организацией.

| Колонка | Тип | Описание |
|---------|-----|----------|
| kiosk_id | int (PK) | Идентификатор киоска |
| org_id | int (nullable) | ID организации — ключевое поле |
| number | int | Номер терминала (из сертификата) |
| address | varchar(256) | Адрес установки |
| serial_number | varchar(50) | Серийный номер |
| status | tinyint | Статус киоска |
| + ещё ~45 колонок | | касса, принтер, валидатор, SIM и т.д. |

**Запрос:** `SELECT org_id FROM Kiosks WHERE number = @number`

### 3.2. Таблица `tb_GS_Group` (база: Service)

Дерево категорий меню. Иерархия через `parentId`.

| Колонка | Тип | Описание |
|---------|-----|----------|
| Id | int (PK) | Идентификатор группы |
| org_id | int | ID организации |
| number | int | Порядковый номер / код группы |
| name | nvarchar(500) | Название категории |
| parentId | int (nullable) | ID родительской группы (NULL или 0 = корень) |

**Запрос:** `SELECT * FROM tb_GS_Group WHERE org_id = @org_id ORDER BY number`

### 3.3. Таблица `tb_GS_Service` (база: Service)

Услуги, привязанные к группам.

| Колонка | Тип | Описание |
|---------|-----|----------|
| Id | int (PK) | Идентификатор услуги |
| group_id | int | FK на tb_GS_Group.Id |
| tsp_code | int | Уникальный код услуги (TSP-код) |
| name | nvarchar(500) | Название услуги |
| printname | nvarchar(500) | Название для чека |
| price | int | Цена в копейках |
| protype | bit | Флаг |
| tempnumber | int | Временный номер |
| protypenumber | int | Номер прототипа (шаблона) |
| action | bit | Флаг акции |

**Запрос:** `SELECT * FROM tb_GS_Service WHERE group_id = {g.Id} ORDER BY tsp_code`

## 4. Модели в коде (C#)

### clsMenuItem (выходная JSON-модель)
```csharp
public class clsMenuItem {
    public string name;              // название (не сериализуется если null/empty)
    [JsonIgnore] public int number;  // номер группы (не сериализуется)
    public int code;                 // tsp_code услуги (>0 — сериализуется)
    public int prototypeid;          // protypenumber (>0 — сериализуется)
    public string printname;         // название для чека
    public string price;             // цена строкой ("0" не сериализуется)
    public List<clsMenuItem> items;  // дочерние элементы
}
```

### Group (входная модель из БД)
```csharp
public class Group {
    public int Id;
    public int number;
    public string name;
    public int ParentId;
    public List<Service> services;
}
```

### Service (входная модель из БД)
```csharp
public class Service {
    public int Id;
    public int tsp_code;
    public string name;
    public string printname;
    public int protypenumber;
    public int price;
}
```

## 6. Ключевые особенности

1. **Схлопывание дерева:** Корневая группа "Раздел главного меню" (parentId=NULL) одна, остальные (parentId=0) — её дочерние. После `root.items = root.items[0].items` в ответе сразу список категорий без обёртки.

2. **N+1 запрос:** 1 запрос на org_id + 1 на группы + N на услуги (по одному на группу). Для org=424 это 15 запросов.

3. **SQL injection:** Строка `WHERE group_id = " + g.Id` — конкатенация, но `g.Id` — int из БД, уязвимости нет.

4. **Цена в копейках:** `price` хранится как int (копейки), сериализуется как string.

5. **ShouldSerialize паттерн:** Newtonsoft.Json условно сериализует поля — пустые/нулевые не попадают в ответ. Услуги с `price=0` не показывают цену, с `prototypeid=0` не показывают prototypeid.

6. **База `Service`:** Строка подключения получается динамически через HTTP к `AppConfig.EtranConfig?function=dbconn&dbname=Service`.

```
Kiosks (Service DB)
  │
  │ number ← TerminalNumber (из сертификата)
  │ org_id
  ▼
tb_GS_Group (Service DB)
  │ Id (PK)
  │ org_id ← Kiosks.org_id
  │ parentId → self-referencing (дерево)
  │
  ▼
tb_GS_Service (Service DB)
    Id (PK)
    group_id → tb_GS_Group.Id
    tsp_code — уникальный код услуги
    name, printname, price, protypenumber
```
